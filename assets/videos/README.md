# Vídeos (Reels)

1. Coloque aqui os arquivos MP4 (vertical 9:16, de preferência até 10 MB cada).
   Ex.: `assets/videos/egao-sushi.mp4`
2. No `projects.json`, preencha o campo `"video"` do projeto: `"video": "assets/videos/egao-sushi.mp4"`
3. Rode `npm run prints` (ou só faça o push: o GitHub Actions roda sozinho).
   O pôster (capa) é gerado automaticamente em `assets/videos/egao-sushi-poster.webp`.

A seção de vídeos só aparece na página quando pelo menos um projeto tem vídeo.
